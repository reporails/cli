**Discovery**: `.cursor/rules/` scanned recursively for `.mdc` and `.md` files. Skills discovered from `.cursor/skills/`, `.claude/skills/`, `.codex/skills/`, `.agents/skills/` (project) and `~/.cursor/skills/`, `~/.claude/skills/`, `~/.codex/skills/` (personal). Subagents from `.cursor/agents/`, `.claude/agents/`, `.codex/agents/` (project) and user equivalents. AGENTS.md read from project root and nested subdirectories. Plugins via marketplace, community (cursor.directory), or local (`~/.cursor/plugins/local/`).

**Precedence**: Team Rules > Project Rules > User Rules. Enterprise hooks > Team hooks > Project hooks > User hooks.

**Rule modes** (controlled by frontmatter):
- **Always apply** (`alwaysApply: true`): Loaded into every session
- **Intelligent** (`alwaysApply: false` + `description`): Agent decides based on description
- **File-scoped** (`globs: [...]`): Applied when matching files are active
- **Manual** (no `alwaysApply`, no `globs`): Only via `@`-mention in chat

**Hook types**: Command (shell script with JSON stdin/stdout), Prompt (LLM-evaluated conditions). Hooks can block via `permission: "deny"` or exit code 2.

**BugBot**: Automated PR review. 4-tier rule hierarchy: Team > Repository (learned + manual) > Project (.cursor/BUGBOT.md) > User. Learned rules auto-generated from team activity. Autofix spawns Cloud Agents.
