**Discovery**: Recursive upward from cwd for CLAUDE.md. Downward subtree CLAUDE.md loaded on-demand. Skills discovered from `.claude/skills/`, `~/.claude/skills/`, managed settings, and plugins.

**Precedence** (highest to lowest): Managed policy > Project > User > Auto memory. For CLAUDE.md: more specific path wins. `CLAUDE.local.md` takes highest user precedence.

**Imports**: `@path/to/file` syntax in CLAUDE.md, recursive up to 5 hops.

**Commands → Skills merge**: `.claude/commands/deploy.md` and `.claude/skills/deploy/SKILL.md` both create `/deploy` and work the same way. Existing commands keep working. Skills add optional features (directory, frontmatter, model-triggered loading). If both exist with the same name, skill takes precedence.
