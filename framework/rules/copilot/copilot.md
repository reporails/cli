**Discovery**: Fixed paths under `.github/` for most surfaces. Exception: `AGENTS.md` uses directory tree walking (nearest ancestor wins; experimental `chat.useNestedAgentsMdFiles` for recursive subfolder discovery). VS Code also discovers from `.claude/rules` and `.claude/CLAUDE.md`. Additional discovery paths configurable via `chat.instructionsFilesLocations`, `chat.promptFilesLocations`, `chat.agentSkillsLocations`.

**Precedence**: Org instructions + repo instructions combined. `excludeAgent` can opt out specific agents (`code-review`, `coding-agent`). Prompt files are manually invoked (not auto-applied like instructions).

**Hook events (platform-dependent)**:
- GitHub coding agent (13 documented events as of 2026-06, expanded from 6): includes `sessionStart`, `sessionEnd`, `userPromptSubmitted`, `preToolUse` (can deny), `postToolUse`, `errorOccurred`, plus `subagentStart`/`subagentStop`, `preCompact`, `notification`, `permissionRequest`. Hook definitions require `type: "command"`, `bash`/`powershell` script paths, optional `timeoutSec` (default 30).
- VS Code (8 events): `SessionStart`, `UserPromptSubmit`, `PreToolUse` (can deny/ask/allow), `PostToolUse`, `PreCompact`, `SubagentStart`, `SubagentStop`, `Stop`. VS Code uses `command` field with OS-specific overrides, and also searches `.claude/settings*.json` for hook definitions.

**Prompt files**: Frontmatter supports `agent` (ask/agent/plan/custom), `model`, `tools` (including MCP tools via `<server>/*`). Body supports `${variableName}` substitution, `#tool:<name>` references, relative markdown links to workspace files.
